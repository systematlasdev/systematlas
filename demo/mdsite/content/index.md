# Welcome to mdsite

**mdsite** is a tiny static site generator used as a demo for flow-trace.

It turns Markdown into HTML. Read the [guide](guide.md) or learn more on the
[about](about.md) page. External links like [Node.js](https://nodejs.org) are
kept as-is.

- Zero dependencies
- Frontmatter + `inline code`
- Sitemap generation
